## 기능 요구사항

### 1.입력

- 사용자로부터 **자동차 이름 목록**을 입력 받는다.
    - 쉼표(,)를 기준으로 이름을 구분한다.
    - 각 이름은 5자 이하로만 입력 가능하다.
    - 잘못된 값 입력 시 `IllegalArgumentException`을 발생시키고, 프로그램을 종료한다.
- 사용자로부터 **시도 횟수**를 입력 받는다.
    - 시도 횟수는 정수형(int) 값으로만 입력 가능하다.
    - 잘못된 값 입력 시 `IllegalArgumentException`을 발생시키고, 프로그램을 종료한다.

### 2. 자동차 생성 및 관리

- 입력받은 이름들을 이용해 자동차 객체를 생성한다.
- 각 자동차는 Dto 또는 객체로 관리하며, 이동 거리 상태를 저장한다.

### 3. 자동차 이동

- `Randoms.pickNumberInRange`을 통해 0~9 사이의 정수를 무작위로 생성한다.
- 각 자동차는 매 시도마다 무작위 값을 받아 전진 또는 정지 여부를 결정한다.
    - 4 이상일 경우 자동차는 전진한다.
    - 0 ~ 3 사이일 경우 자동차는 정지한다.
- 각 자동차의 이동 거리는 누적되어 관리된다.

### 4. 출력

- 각 라운드마다 자동차의 이동 결과를 출력한다.
    - 자동차 이름과 같이 출력되게 구현한다.
    ```bash
    pobi : -
    woni :
    jun : -
    
    pobi : --
    woni : -
    jun : --
    
    pobi : ---
    woni : --
    jun : ---
    
    pobi : ----
    woni : ---
    jun : ----
    
    pobi : -----
    woni : ----
    jun : -----


- 경주가 완료된 후 **우승자들**을 출력한다.
    - 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
    - 가장 멀리 이동한 자동차가 우승한다.
    ```bash
    최종 우승자 : pobi, jun

### 5. 예외처리

- 예외 발생 시 IllegalArgumentException을 발생시킨 후 애플리케이션을 종료한다.
- System.exit()는 사용하지 않는다.
- 입력 관련 예외
    1. 자동차 이름
        - 문자가 아닌 값(공백, 숫자, 특수문자)을 포함하여 입력 시 예외 발생
        - 이름이 5자를 초과할 경우 예외 발생
        - 입력값이 비어 있을 경우 예외 발생
        - 이름이 중복될 경우 예외 발생

    2. 시도 횟수
        - 0 이하의 값, 음수, 소수, 문자열, 특수문자 입력 시 예외 발생
        - 입력값이 비어 있을 경우 예외 발생
        - int 범위를 초과하는 수 입력 시 예외 발생
    3. 자동차 수
        - 자동차가 2대 이상이 아닐 경우 예외 발생
        - int 범위를 초과하는 수 입력 시 예외 발생

## 테스트

### 1. 정상 동작 테스트

| 테스트 항목    | 검증 내용                                   |
|-----------|-----------------------------------------|
| 자동차 이름 입력 | 정상적인 이름 입력 시 `Car` 객체가 생성되는지 확인         |
| 자동차 전진 조건 | 무작위 값이 4 이상일 경우 전진하는지 검증                |
| 자동차 정지 조건 | 무작위 값이 3 이하일 경우 정지 상태인지 검증              |
| 시도 횟수 반복  | 입력된 횟수만큼 반복이 수행되는지 확인                   |
| 이동 결과 출력  | 각 라운드마다 이름과 이동 거리가 올바르게 표시되는지 검증        |
| 우승자 판별    | 가장 멀리 이동한 자동차가 우승자로 선택되는지 확인            |
| 공동 우승 처리  | 이동 거리가 동일한 경우 여러 우승자가 쉼표로 구분되어 출력되는지 확인 |

### 2. 예외 테스트

| 테스트 항목            | 입력값 예시                    | 기대 결과                         |
|-------------------|---------------------------|-------------------------------|
| 이름 5자 초과          | `"abcdf"`                 | `IllegalArgumentException` 발생 |
| 이름 비어 있을 경우       | `"", " "`                 | `IllegalArgumentException` 발생 |
| 이름에 숫자/특수문자/공백 포함 | `"pobi1", "@pobi, po bi"` | `IllegalArgumentException` 발생 |
| 이름 중복             | `"pobi,pobi"`             | `IllegalArgumentException` 발생 |
| 자동차 수 부족          | `"pobi"`                  | `IllegalArgumentException` 발생 |
| 시도 횟수 음수          | `"-3"`                    | `IllegalArgumentException` 발생 |
| 시도 횟수 0           | `"0"`                     | `IllegalArgumentException` 발생 |
| 시도 횟수 정수 아닌 경우    | `"abc", "1.5"`            | `IllegalArgumentException` 발생 |
| int 범위 초과         | `"9999999999"`            | `IllegalArgumentException` 발생 |

### 3. 최종 성공 테스트 (전체 시나리오 검증)

| 테스트 항목     | 검증 내용                                        |
|------------|----------------------------------------------|
| 전체 경주 프로세스 | 자동차 생성 → 이동 → 우승자 판별까지 전체 흐름이 정상적으로 수행되는지 확인 |
| 결과 출력 검증   | 모든 라운드 결과 및 최종 우승자 출력이 요구사항 형식대로 표시되는지 확인    |
